## 主要修复

- 只读 /home 挂载下，Docker 归档拷贝拒绝可写子挂载：改为容器内流式解包。
- 换容器后旧虚拟环境的 Python 路径失效：实际启动 AISBench 检查，失效环境先备份再重建。
- AISBench 的 retry=0 实际等于零次请求：将界面“额外重试次数”转换为初始请求加重试。
- 请求超时旧补丁未覆盖预热/推理共享会话：同时设置共享会话超时，且复用旧环境也加载当前补丁；0.2 秒配置实测约 0.201 秒退出。
- 任务结束后僵尸进程导致永久忙碌：区分僵尸与活跃进程，自动确认并释放中心占用。
- 改选容器后的登记/持久连接不匹配：按经过核验的部署接续，保留端口与凭据并自动迁移。
- Runner 生成性能数据时的 AutoTokenizer 环境：关闭设备后端自动加载，并保留完整异常堆栈。
- 同一 Runner 的同页选择卡住：确认空闲后重新加载页面，并提供超时恢复。
